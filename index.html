05 CryptoBacktester view on GitHub →

A cryptocurrency backtesting engine for evaluating trading strategies against historical market data. Pulls OHLCV candlestick data via ccxt, caches it locally in SQLite, and simulates a moving-average crossover strategy with realistic order execution.

  • Realistic trade execution modeling — next-bar open fills, exchange fees, and slippage
  • Advanced gap-detection that extrapolates the exchange's timestamp grid to catch missing candles without false positives
  • Full trade ledger with equity curve charting and exportable JSON/CSV performance reports
  • Fully configurable via CLI flags — symbol, timeframe, moving-average windows, starting cash, fees, and slippage
PythonSQLiteccxtpandas
